# ExamPoll — 시험 일정 투표 서비스

교수가 시험 후보 시간대를 등록하면, 학생들이 불가능한 시간에 투표합니다.  
투표 마감 후 시스템이 가장 많은 학생이 참석 가능한 최적 시간을 자동 추천합니다.

---

## 실행 방법

### 요구사항

- **Node.js** v14 이상 (외부 패키지 설치 불필요)

### 서버 시작

```bash
node server.js
```

브라우저에서 `http://localhost:8080` 접속.

### 외부 공유 (ngrok)

같은 네트워크 밖의 다른 기기(학생 스마트폰 등)와 공유하려면 ngrok이 필요합니다.  
`node server.js` 실행 시 ngrok이 자동으로 시작되며, 터미널에 공개 주소가 출력됩니다.

```
ngrok 공개 주소    → https://xxxx.ngrok-free.app
```

해당 주소를 학생들에게 공유하면 됩니다. 교수와 학생 모두 같은 서버에 접속하므로 데이터가 실시간으로 공유됩니다.

> ngrok을 별도로 실행하지 마세요. 서버와 ngrok을 동시에 두 개 실행하면 충돌이 발생합니다.

---

## 사용 흐름

### 교수 (투표 개설)

1. 브라우저에서 서비스 접속
2. **교수 로그인 · 투표 개설** 클릭 → 회원가입 후 로그인  
   (세종대학교 이메일 `@sejong.ac.kr` 필요)
3. **+ 새 투표 개설** 클릭
4. 과목명, 분반, 투표 마감 일시, 후보 시간대 입력 후 생성
5. 생성된 **공유 링크** 또는 **QR 코드**를 학생들에게 전달
6. 투표 마감 후 결과 페이지에서 최적 시간 확인

### 학생 (투표 참여)

1. 교수에게 받은 링크 또는 QR 코드로 접속
2. 이름과 학번 입력 (로그인 불필요)
3. 참석 **불가능한** 시간대만 체크
4. **투표 제출** 클릭
5. 같은 학번으로 재제출하면 기존 투표가 수정됩니다

---

### DB 초기화

데이터를 모두 초기화하려면 아래 스크립트를 실행하세요.

```bash
python3 init_db.py
```

세 JSON 파일(`db_professors.json`, `db_polls.json`, `db_votes.json`)이 빈 배열로 초기화됩니다.

---

## 데이터 저장 구조

데이터는 `data/` 디렉토리의 JSON 파일에 저장됩니다.

| 파일 | 내용 |
|------|------|
| `data/db_professors.json` | 교수 계정 (이메일, 비밀번호 해시, 이름) |
| `data/db_polls.json` | 투표 공간 (과목명, 후보 시간대, 마감 일시) |
| `data/db_votes.json` | 투표 내역 (학번, 이름, 불가 슬롯 목록) |

> 비밀번호는 SHA-256으로 해시되어 저장됩니다.  
> `data/` 디렉토리는 서버 외부에서 직접 접근할 수 없도록 차단되어 있습니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 투표 기한 설정 | 마감 일시 이후 자동으로 투표 차단 |
| QR 코드 생성 | 투표 링크를 QR로 즉시 공유 |
| 최적 시간 추천 | 마감 후 불가 응답이 가장 적은 시간대 자동 추천 |
| 중복 투표 방지 | 같은 학번으로 재제출 시 기존 투표 덮어쓰기 |
| 반응형 UI | 모바일 환경 지원 |
