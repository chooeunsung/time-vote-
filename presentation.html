문제 정의

🏫

많은 교수님들이 정규 수업 시간 외에 시험을 선호하지만, 학생들의 가능 시간대를 파악하는 방법이 없다.

입력창 포커스 효과

/* style.css */
input[type=text],
input[type=email],
input[type=password] {
  background: #F9FAFB; /* 기본: 연회색 */
  border: 1.5px solid #E5E7EB;
  transition: all .18s;
}

input:focus {
  outline: none;
  background: #ffffff; /* 포커스: 흰색 */
  border-color: #2563EB;
  box-shadow: 0 0 0 3px #EFF6FF;
}

input::placeholder {
  color: #9CA3AF;
  opacity: 1;
}
기본 상태 — 연회색 배경
background: #F9FAFB으로 연회색 처리. 아직 입력 전임을 시각적으로 구분하고 전체 폼의 통일감 유지.
input:focus 가상 선택자
커서 진입 시 배경 → 흰색, 테두리 → 파란색, box-shadow로 외부 글로우 추가. 현재 활성 입력창을 명확히 강조.
transition: all .18s
색상·그림자 변화가 0.18초 동안 부드럽게 전환. 모든 입력창에 동일하게 적용해 일관된 인터랙션 제공.
placeholder 속성
입력 전 안내 텍스트 표시. 교수 이메일 입력란엔 placeholder="example@sejong.ac.kr", 투표 제목엔 placeholder="ex) 웹프로그래밍 1분반"을 사용.

날짜 · 시간 입력 모듈

<!-- admin.js (렌더 함수 내) -->
<input
  type="datetime-local"
  id="poll-deadline"
  step="600"
  onchange="snapTo10Min(this)"
/>

// 10분 단위로 보정하는 함수
function snapTo10Min(input) {
  const d = new Date(input.value);
  const m = Math.round(
    d.getMinutes() / 10
  ) * 10;
  if (m === 60) {
    d.setHours(d.getHours() + 1);
    d.setMinutes(0);
  } else {
    d.setMinutes(m);
  }
  // input.value 갱신 후 반환
}
type="datetime-local"
날짜와 시간을 하나의 입력창에서 선택. 브라우저 기본 달력·시계 UI를 제공해 별도 라이브러리 없이 구현.
JS 보정 함수 snapTo10Min()
onchange 이벤트로 호출. Date 객체로 분(minute)을 반올림 후 input.value 갱신. 59분 → 0분 넘길 때 시(hour)도 자동 보정.
